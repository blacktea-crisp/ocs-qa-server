## 关键决策汇总
1. 语言：Python + FastAPI（大模型/识图生态、异步服务、无需坏掉的 node TLS）。
2. 题库唯一键：`qkey = hash(题干 + 选项排序 + 题型)`，解决"同题不同选项"。
3. 记录：请求级 + 步骤级两层。
4. 桌面形态：纯标准库 Windows 系统托盘（Win32 消息循环 + 原生菜单）。
5. 进程架构：supervisor 为后端唯一管理者（方案 A）。
6. 配置生效：`effective_llm()` 运行期配置优先于 .env。
7. 已知问题：只写方案入文档，0.2.0 实现。

## 主要踩坑（对话中解决）
- GitHub hosts 劫持 + TLS 故障 → 走 ghproxy / Node https。
- ctypes 未声明原型 → 托盘回调崩溃（右键无反应/自动退出）→ 全部声明 argtypes/restype。
- 跨进程 taskkill 权限 → 改用同进程 Popen 句柄 terminate；supervisor 按端口兜底。
- 配置保存不生效 → effective_llm 修复。
- 本机 Get-NetTCPConnection 不可靠 → 用 netstat；跨会话孤儿进程无法杀（换端口测试）。
